
# 💜 Purplle App Clone

## 📌 About the Project
This project is a front-end clone of the Purplle beauty and cosmetics shopping website, developed using HTML and CSS. It recreates the website's layout with a focus on navigation, product displays, and a clean shopping interface.

## ✨ Features
- Navigation bar with menu links
- Dropdown menu for product brands
- Product categories and offers section
- Product cards with prices and discounts
- Shopping cart page
- Wishlist page
- Login page UI
- Hover effects and styling

## 🛠️ Technologies Used
- HTML5
- CSS3
- Font Awesome Icons

## 🚀 How to Run
1. Clone this repository:
   ```bash
   PurpleClon
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

## 🎯 Project Objective
To practice front-end web development by recreating an e-commerce website layout using HTML and CSS.
